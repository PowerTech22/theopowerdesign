# TheoPower website

Plain HTML/CSS/JS, hosted free on GitHub Pages. No build step.

- Edit your details (email, WhatsApp, Paystack public key, bank accounts) in `config.js`.
- Contact form and "I've sent the payment" alerts go to the email in `config.js` via FormSubmit.
  The first submission sends an activation email — click it once.
- Case study text lives in `case-studies.js`.
- To update the site: on GitHub open the file → pencil icon → edit → Commit. It goes live in about a minute.
